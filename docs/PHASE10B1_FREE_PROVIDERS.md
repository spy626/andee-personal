# Andee Phase 10B.1 — Real free-provider routing, preserving original Andee autonomy

Stacked on Phase 10A `538ef60334a01eda36c7fe21f5cc0f20d0d40270`. Branch `agent/andee-phase10b1-free-providers`, Draft PR only. Do not touch main.

## Requirement and boundaries
One original Andee `LocalBrain` remains owner of tools, memory, mascot responses, screen automation, notification triage, autonomous work and voice service. No new model executor, no LYRA module directly transplanted into Andee. Original CodeFlying, local custom backend, Hub, Huoshan/Google/System TTS remain. Do not add direct DeepSeek provider, chargeable calls, retries, model fallback or unconsented provider switching.

## Implementation
- Settings -> AI & Voice -> original Local backend: new opt-in provider chooser. Existing/custom option is the default on all old installs. Actual free model choices:
  - **xKiro**: `deepseek/deepseek-v4.1-flash:free` (via xKiro only) and `qwen/qwen3-coder-plus:free`. On every LLM completion *before sending any messages/screens/tools*, read-only GET public `/v1/models` must verify exact chosen ID, free access tier, tool support and every price component == 0. Authenticated read-only GET `/v1/usage` must verify known remaining free tokens >= 12,000. Any missing or stale metadata, missing key, HTTP error or quota exhaustion fails closed with NO inference POST. No paid fallback. This is stricter than relying on a free-name suffix alone.
  - **Groq**: `openai/gpt-oss-120b` or `openai/gpt-oss-20b`, original LocalBrain functions/tool calls. **Free-account confirmation defaults OFF**; if OFF, no key is supplied and no request can succeed. This confirmation is NOT live billing proof: users should never use a paid Groq account for this free-only option. No automatic paid fallback.
  - **OpenRouter**: `openrouter/free` Auto model only, with a zero-price `provider.max_price` cap in the API payload. No paid models or implicit retry fallback.
- All three share the original `LlmClient.complete` OpenAI tool-calling loop. Legacy requests retain their original DeepSeek-specific `thinking` format; other routes omit it to avoid provider-specific 400. `BrainConfig.sameBackend` includes the free-provider identity so an explicit switch restarts the brain; model tuning on same endpoint/key stays in the original retune logic. No calls without user selecting a free provider with a usable key.
- API credentials are stored by Android Keystore 256-bit AES-GCM in separate private `andee_free_provider_keys` preferences, **never plaintext in voice_prefs or BuildConfig**; not the biometric Vault, which would require fingerprint during ordinary background work. Settings shows blank secret fields with saved-key hints and preserves entered keys across category navigation. Save commits secrets first (fail closed if secure storage fails) then saves the provider/model choice.
- LLM7 and Z.AI are intentionally NOT active in 10B.1. LYRA's LLM7 route is text-only and its Z.AI route coding-only; Andee depends on autonomous tools and screenshots. They need separate capability/free-account verification before exposing as active Andee brains. Voice/Gemini Live still 10C; colors/top Settings still phase 11.

## Verification

Emulator tests: Android Keystore encrypt/decrypt/no plaintext/clear, VoiceConfig local route selection with original mode and endpoint, existing 12 Android smoke/security/navigation tests. New source guard restricts changed files and compares screen, gesture, original service, TTS, biometric Vault, message dispatcher, notifications, autonomous WORK and memory source byte-for-byte to Phase 10A. All earlier Phases 8–10A checks stay enabled. Android Debug, Release/R8, Hub and DCO build on PR. No paid inference or user-key live preflight occurs in CI.

## Before user-phone acceptance
Use spare/test device. Never enter an API key in a screen recording; cover it. Save a free-provider option and key, then close/reopen Settings; confirm model and selected provider persist. Test text and a harmless local screen observation only. xKiro free preflight may deliberately refuse if free pricing/quota/tool metadata is not verified; that is a safety success, not permission to switch to paid. Test existing CodeFlying, original voice, mascot, Vault, and memory. Model tool behavior still requires physical test with user-owned keys and user approval; CI alone is not proof.
